# 🎓 Student Performance Predictor

A simple Machine Learning project built with Python.

## 📌 Project Description

This project predicts whether a student will pass or fail based on:

- Study Hours
- Number of Absences
- Homework Score

The project also analyzes the dataset and visualizes it using charts.

---

## 🛠 Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Joblib

---

## 📊 Features

- Read and save CSV files
- Analyze student data
- Calculate statistics
- Visualize data with charts
- Train a Machine Learning model
- Predict student success
- Save and load the trained model

---

## 📈 Charts

- Bar Chart
- Pie Chart
- Histogram
- Scatter Plot

---

## 🤖 Machine Learning

Algorithm used:

- Logistic Regression

Model Input:

- Study Hours
- Absences
- Homework Score

Output:

- Pass (1)
- Fail (0)

---

## 🚀 How to Run

```bash
pip install pandas matplotlib scikit-learn joblib
```

Then run:

```bash
python main.py
```
